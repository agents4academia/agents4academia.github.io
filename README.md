# agents4academia.github.io

Source for the Agents4Academia hackathon site — a two-week event on AI
agents for the scientific process, organised jointly by researchers at
Oxford, NUS, and NTU, 14–26 June 2026.

Plain static HTML + CSS, served by GitHub Pages at
[agents4academia.github.io](https://agents4academia.github.io). No build step.

## Structure

- `index.html` — about
- `schedule.html` — schedule (TBA)
- `resources.html` — prep materials (TBA)
- `assets/css/style.css` — shared styles

## Local preview

Open `index.html` directly in a browser, or serve the directory:

```
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
